# Wordle Solver

A command-line word-search solver written in C. The project uses string
manipulation, pointers, searching algorithms, and automated testing to
iteratively identify a target word from a vocabulary.

## Technologies

- C
- Make
- Linux
- Git

## Features

- Word-search solving algorithm
- Vocabulary-based searching
- String and pointer manipulation
- Automated test cases
- Modular C implementation
